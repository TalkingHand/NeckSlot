## Assumptions
assume	InventoryItem.attachmentType comes from the script item when an item is made or loaded (not saved)	Item.InstanceItem -> setAttachmentType; if saved per item, old items would keep no type
assume	IsoGameCharacter.isEquipped(item) is true for worn clothing	ISHotbar:update then removes the hung model while worn; else a worn mask is also drawn on the neck
assume	ModelManager draws an attached item only if getStaticModelException() is set	no eligible vanilla item has a StaticModel (checked 42.21.0), so hung items are invisible
assume	IsoGameCharacter.setWornItem moves an exclusive worn item off (the swap finds it by comparing worn lists)
